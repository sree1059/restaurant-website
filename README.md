# Vantillu — Authentic Telugu Restaurant

A modern, responsive web application for **Vantillu**, an authentic Telugu dining experience featuring traditional home recipes, slow-cooked Hyderabadi biryanis, gongura specialties, banana-leaf thalis, and handcrafted sweets.

## Features

- **Hero Experience**: Immersive parallax visuals with smooth scroll animations, warm heritage color palette, and direct booking actions.
- **Story Section**: Rich storytelling capturing three generations of wood-fired culinary heritage in Hyderabad.
- **Signature Dishes**: Bento-grid showcase with hover transitions highlighting traditional dishes (Hyderabadi Dum Biryani, Banana Leaf Thali, Gongura Mamsam, Pesarattu & Upma, etc.).
- **Interior & Atmosphere**: Photography grid showcasing the restaurant's hand-plastered arches, terracotta tiles, and brass accents.
- **Digital Menu Preview & Dedicated Menu Page**: Full interactive menu with categories, descriptions, INR pricing, and mobile-first experience.
- **Guest Testimonials**: Carousel reviews from diners celebrating authentic Andhra flavors.
- **Interactive Map & Contact**: Address in Banjara Hills, opening hours, one-click WhatsApp reservation and ordering, and Google Maps embed.
- **Smooth Momentum Scrolling**: Integrated Lenis scroll library for luxury dining feel.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4 with custom serif typography (`Cormorant Garamond`, `Dancing Script`, and `Manrope`)
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router v7

## Running Locally

```bash
npm install
npm run dev
```

The application runs on port `3000` at `http://localhost:3000`.
